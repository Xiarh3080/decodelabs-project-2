# Responsive Web Layout – Project 2

**Frontend Development Internship – DecodeLabs**

---

# 📌 Project Overview

This project was developed as **Project 2** of the **Frontend Development Internship** at **DecodeLabs**.

The objective of this project is to design and develop a **fully responsive website** using modern HTML5 and CSS3 techniques. The website adapts seamlessly across desktops, tablets, and mobile devices while maintaining a clean, professional, and user-friendly interface.

The project demonstrates responsive web design principles using **Flexbox**, **CSS Grid**, and **Media Queries** without relying on external CSS frameworks.

---

# 🎯 Project Objectives

* Build a responsive webpage using HTML5 and CSS3.
* Ensure compatibility across desktop, tablet, and mobile devices.
* Implement responsive navigation.
* Maintain proper spacing, alignment, and layout consistency.
* Apply modern responsive design techniques.
